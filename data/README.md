# data/

Nothing in this folder except `demo/` is checked in -- the real files are
brand-specific, some are large, and they're regenerated by `scripts/`. Here's
the full path from zero to a real evaluation run.

## 1. Get the raw dataset (blocked on you -- Claude's sandbox can't reach kaggle.com)

```
pip install kaggle
kaggle datasets download -d thoughtvector/customer-support-on-twitter
unzip customer-support-on-twitter.zip -d data_raw/
```

## 2. Pick a brand

```
python scripts/01_discover_brands.py --input data_raw/twcs.csv --out_dir data/
```

Produces `data/brand_candidates_summary.csv` (evidence: reply volume,
boilerplate-DM rate, followup rate, composite score -- lower composite is
better) and `data/subsample_twcs.csv` (top-10 brands, capped 20k rows/brand).
Read the summary, pick the brand with the best composite score, and set it
as `--brand` in the next two steps. Also worth 10 minutes: open
`subsample_twcs.csv`, filter to that brand, and skim ~50 real replies --
that's what tells you the brand's actual tone/signoff for `config.Brand`
(quantitative selection evidence doesn't include voice).

## 3. Build the retrieval corpus

```
python scripts/02_build_retrieval_corpus.py --input data/subsample_twcs.csv --brand <BRAND> --out data/retrieval_corpus.csv
```

## 4. Sample and label the golden set

```
python scripts/03_sample_golden_set.py --input data/subsample_twcs.csv --n 200 --out data/golden_set_template.jsonl
```

Then open the output and hand-fill `ground_truth_intent`,
`ground_truth_resolution`, `difficulty`, and `expected_action` per case (see
the script's docstring). Target size is 150-250. Save the completed file as
`data/golden_set.jsonl`.

## 5. Run it

```
python scripts/04_run_baselines.py --golden_set data/golden_set.jsonl
python scripts/05_run_pipeline.py --corpus data/retrieval_corpus.csv --message "..."
python scripts/06_run_eval.py --corpus data/retrieval_corpus.csv --golden_set data/golden_set.jsonl --out eval_report.json
```

Steps 5's last two scripts need `GEMINI_API_KEY` (and `GROQ_API_KEY` for
eval's judge) in `.env`. Add `--fake-llm` to either one to smoke-test the
wiring with zero API calls.

## demo/ (checked in, synthetic)

`subsample_demo.csv`, `retrieval_corpus_demo.csv`, and `golden_set_demo.jsonl`
are fabricated data for two fictional brands, built specifically to exercise
every script above without needing the real Kaggle download or API keys
(see `--fake-llm`). Real numbers always require the real dataset -- see
`REPORT.md` for exactly which numbers in this project are real vs.
synthetic-smoke-test.
